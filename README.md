## Hino FC — Ruta 35

A small 3D truck driving game made with [Three.js](https://threejs.org/).

One white Hino FC cab-over truck, a flat plain, and a straight 1.2 km road to the depot. Drive to the end of the route and stop inside the glowing green delivery zone.

### Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Accelerate | `W` / `↑` | GAS |
| Brake / reverse | `S` / `↓` / `Space` | BRAKE |
| Steer | `A` `D` / `←` `→` | ◀ ▶ |
| Pause | `P` / `Esc` | Pause button |
| Restart | `R` | — |
| Mute | `M` | Speaker button |
| Horn | `H` | — |

The best run time is stored locally in the browser.

### Run locally

```sh
RUNTIME_DIR=... ./start.sh   # OMGithub preview server on port 3002
```

The game is a static site: open `index.html` through any static file server.
